# StudyQ – AI Study Platform

A full-stack AI-powered study assistant that turns PDF documents into quizzes, notes, and analytics.

## Project Structure

```
Antygravity/
├── studyq-backend/    # Flask REST API
└── studyq-frontend/   # React + Vite SPA
```

## Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React 18, Vite, Tailwind CSS v3, Three.js, Recharts |
| Backend | Flask, SQLAlchemy, Flask-JWT-Extended |
| Database | PostgreSQL (Neon) |
| AI | Google Gemini 1.5 Flash |
| PDF | PyMuPDF (fitz) |

## Quick Start (Local)

### Backend
```bash
cd studyq-backend
python -m venv venv && venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env   # fill in DATABASE_URL and GEMINI_API_KEY
python app.py
# → http://localhost:5000
```

### Frontend
```bash
cd studyq-frontend
npm install
npm run dev
# → http://localhost:5173
```

## Required Environment Variables

### Backend (`.env`)
| Variable | Description |
|----------|-------------|
| `DATABASE_URL` | PostgreSQL connection string |
| `JWT_SECRET_KEY` | Secret key for JWT signing |
| `GEMINI_API_KEY` | Google Gemini API key |

### Frontend (`.env`)
| Variable | Description |
|----------|-------------|
| `VITE_API_BASE_URL` | Backend URL (default: `http://localhost:5000`) |

## Features

- 📄 **PDF Upload** – drag-and-drop PDF → text extracted with PyMuPDF
- 🤖 **AI Quiz Generation** – 10 MCQs generated by Gemini with strict JSON validation
- 📝 **AI Study Notes** – auto-summarized notes on upload
- 🎯 **Quiz Attempt** – paginated MCQ interface with answer tracking
- 📊 **Analytics** – accuracy trend charts, rolling average, attempt history table
- 🔐 **JWT Auth** – bcrypt password hashing, persistent sessions
